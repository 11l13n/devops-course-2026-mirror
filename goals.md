# Цели на семестр

1. Освоить полный цикл работы с Git: создавать отдельную ветку для задачи,
   открывать Pull Request, учитывать замечания и разрешать конфликты.
   Результат: выполненные практические работы и проверяемая история коммитов.
2. Научиться запускать Python-приложение в Docker на Linux и описывать
   окружение в Dockerfile. Результат: запуск проекта по инструкции из README.
3. Настроить GitHub Actions для автоматического запуска тестов при push
   и Pull Request. Результат: успешная проверка учебного проекта в CI.
