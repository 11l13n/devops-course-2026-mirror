# Сравнение Git и SVN

## 1. Почему ветвление в Git считают дешёвым

Ветка Git — ссылка на коммит. Создание ветки выполняется локально и не
копирует весь проект. В SVN ветка представлена копией каталога внутри
центрального репозитория. При этом SVN использует cheap copies, поэтому
считать само создание ветки обязательно медленным или дорогим неверно.
Различаются прежде всего модель работы и зависимость от центрального сервера.

## 2. Можно ли сделать коммит SVN без интернета

Для коммита нужен доступ к репозиторию. Если он находится на недоступном
удалённом сервере, закоммитить изменения нельзя; их можно оставить в рабочей
копии. Интернет не обязателен, если сервер доступен по локальной сети или
репозиторий расположен локально. В Git коммиты сохраняются в локальный
репозиторий, а сеть требуется при обмене изменениями с удалённым сервером.

## 3. Когда SVN может быть предпочтительнее

SVN подходит для существующей инфраструктуры с центральным репозиторием,
разграничением доступа к каталогам и процессом блокировки файлов, которые
неудобно сливать автоматически, например двоичных графических материалов.
Выбор зависит от процессов команды и стоимости миграции, а не только от
популярности системы.
