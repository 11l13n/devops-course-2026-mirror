# Git в VS Code и в терминале

## Что удобно в VS Code

1. Source Control показывает изменённые файлы и позволяет открыть сравнение
   с последним коммитом рядом с исходным текстом. Это помогает проверить
   каждую добавленную строку перед сохранением изменений.
2. Кнопка Stage Changes добавляет выбранный файл в индекс, а поле Message
   и кнопка Commit позволяют создать коммит прямо в редакторе.
3. Граф истории показывает автора, сообщения коммитов и положение веток
   рядом с файлами проекта.

## Что удобнее в терминале

Interactive rebase и настройку нескольких remote удобнее выполнять
командами: видны точные аргументы и последовательность действий,
а вывод можно сохранить и использовать при проверке результата.

## Выполненная проверка

В VS Code открыт diff README.md, файл добавлен в индекс через Source Control
и создан коммит `docs: add coursework index in VS Code`.
